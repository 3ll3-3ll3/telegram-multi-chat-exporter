# TG Exporter v0.3.0 — Candidate Notes

> **未发布。** 本文记录第三代 Candidate。未经用户真实账号验收与明确发布授权，不创建或覆盖 GitHub Release `v0.3.0`。

## 当前 Candidate 状态

Issue #22 / KI-001 已修复：`current unread` 不再使用 catalogue refresh 时的旧边界，而是在**每个群真正开始执行导出时**单独冻结：

```text
lower = read_inbox_max_id at this group's export start
upper = latest_message_id at this group's export start
export only lower < id <= upper
```

同一 frozen snapshot 同时用于该群本次 JSON 导出与 optional read acknowledgement。snapshot 之后到达的新消息不进入本次导出，也不会被本次 read-ack 标已读。Basic Group → Supergroup 的 current-unread 只刷新当前 logical Supergroup；legacy Basic Group 不参与 current-unread。

## 核心变化

v0.3.0 在 single-daemon / Windows Named Pipe IPC 基础上增加 Personal Account Reader，并已把正式 `main@v0.1.10` 纳入 PR #20 ancestry。

```text
TGExporter GUI ─┐
               ├→ TG daemon → Telegram user Session
tgctl / Codex ─┘
```

GUI 与 tgctl 不再各自 direct-open SQLiteSession；正常 v0.3 GUI + v0.3 tgctl 可以同时存在。

## Reader 能力

```text
tgctl account get
tgctl dialogs list
tgctl chats get
tgctl chats members
tgctl messages history
tgctl messages search
tgctl messages get
tgctl topics list
tgctl topics history
tgctl media download
```

- dialogs 覆盖 group/supergroup/channel/private/bot/Saved Messages/archive/forum/folders；
- default page 100 / max 500；HMAC/query-bound opaque cursor；
- rich messages：structured sender、reply、forward、entities、reactions、poll、service action、media metadata 等；
- Basic Group→Supergroup logical history current→legacy，唯一键 `(source_chat_id,message_id)`；
- migrated global/single-chat search cursor 已加固；
- owner/admin/member 是查询时 current snapshot；anonymous/send-as 不反推个人；
- advanced search 支持 sender/time/type/topic/link/真实 URL domain；
- Forum topics；
- media 默认 metadata-only，显式下载采用 plan → confirmation token → download，normal 20 files / 500 MiB，explicit large 最大 200 files / 5 GiB，`.part` 成功后 atomic rename。

## Compatibility / safety

保留 `status/chats list/messages search/messages get/forward/send`。现有 write safety 不放松：true forward、plain-text send、dry-run、20/200 forward cap、AMBIGUOUS_CHAT、FloodWait structured stop、write outcome unknown no retry、export 时 real write 拒绝。

v0.1.10 UTF-8 console fix、source regression，以及 standalone + portable packaged `SESSION_BUSY` JSON/native exit 8 gate 已 forward-port。

普通日志不得记录 credentials、Session、access_hash/file_reference、message body/caption/URL text/media filename。

## Issue #22 regression coverage

自动化已覆盖：

- stale catalogue state 被 export-start state 替换；
- frozen upper bound 后的新消息不属于本次 run；
- multi-group batch 每个群轮到执行时分别抓 snapshot；
- export 与 read-ack 使用同一 frozen lower/upper；
- export failure 不 read-ack；
- JSON success + read-ack failure 保留 JSON；
- migrated legacy peer 即使先出现，也不会被 current-unread 误用。
